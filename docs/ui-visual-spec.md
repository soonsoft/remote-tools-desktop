# remote-tools 桌面端 · 视觉设计规范

- 版本：1.0（定稿）· 2026-09-19
- 设计方向：Friendly Geometric Candy 暗色适配「深夜游戏机」（轮盘 4 号），亮色版「白日街机」
- 活参考：`design-demos/roulette.html`（本规范的唯一权威实现，token 逐字一致）
- 决策史：`design-demos/direction-approved.md`（11 轮迭代 + 定稿）
- 服务对象：Plan B（remote-tools-desktop）Task 8 的 `ui/` 实现

---

## 1 · 设计立场

**隐喻**：海关/门卫。远方来客（服务器 agent）、本地关卡（本应用）、通关记录（指令流水）。
**气质**：可靠、克制、诚实、"看得见的安全感"。红色是全应用唯一的强视觉时刻（危险确认），其余糖果色全部绑定语义，不做装饰。

**主题**：暗色默认（用户偏好），亮色可切换，localStorage 记忆（`rt-theme`）。

---

## 2 · 材质坡道（本设计的骨架）

```
OS 窗口（系统阴影/圆角——方案 1，不可控也不必控）
  ↓ 同族对话
① 清玻璃框（窗体本体：--glass + backdrop-blur + 顶缘高光 --rim）
     标题栏、侧栏、底条 = 透明背景，与窗体是同一片玻璃
  ↓ 留白（上右 10px，左贴侧栏、底沉底条）
② 乳白内容卡（--card，16px 圆角，承载全部内容视图）
  ↓ 卡内
③ 糖果卡（--surface 实底卡片：横幅、流水行、输入组）
  ↓
④ 糖果按键（硬阴影立体，同色相加深做厚度）
```

浮层（确认弹窗）= **全场最亮焦点**：暗色比内容卡亮一档（--glass-strong），亮色为微蓝白（.92）。

### 三条玻璃铁律（实现时必须遵守）

1. **实底规则**：内容卡必须有实底；半透明染料只能叠在实底上，禁止直接坐在玻璃层上（浮层自身的玻璃除外）。违反实例：`.row.deny` 曾用 6% 红染无实底，玻璃化后溶解。
2. **合成规则**：`backdrop-blur` 元素的有效颜色 = 自身 α×本色 + 背后物颜色。玻璃叠玻璃/叠卡时必须算合成结果，不能只看 token 本值（弹窗曾因吸色恰好等于 surface 而融进卡片）。
3. **单调递进规则**：每个主题内中性色家族严格单调——暗色（暗→亮）硬阴影 < 玻璃框 < 糖果卡 < 内容卡 < 弹窗；亮色（亮→暗同理反向）元素底色最浅 < 边框 < 硬阴影（阴影是家族最深中性色）。全家族同色温：暗色全近黑、亮色全冷调净白。

### 3.3 语义糖果色（双主题不变——品牌签名）

| 语义 | 主色 | 加深（按钮厚度） | 上字色 | 作文字用时 |
|---|---|---|---|---|
| 绿 = 放行/连接 | `--green #58CC02` | `--green-deep #3E9402` | `--on-green #0F2B00` | `--ok-text`：暗 `#58CC02` / 亮 `#3E9402` |
| 黄 = 待确认 | `--yellow #FFC800` | `--yellow-deep #C29500` | `--on-yellow #2B1D00` | `--warn-text`：暗 `#FFC800` / 亮 `#8A6D00` |
| 蓝 = 交互/信息 | `--blue #1CB0F6` | `--blue-deep #0F86C4` | `--on-blue #03293E` | `--accent-text`：暗 `#1CB0F6` / 亮 `#0B72B0` |
| 红 = 拒绝·危险 | `--red #FF4B4B` | `--red-deep #C22B2B` | `--on-red #33060B` | `--red-text`：暗 `#FF6B6B` / 亮 `#D22B2B` |

规则：糖果色作**底色**时双主题同值；作**文字**时必须换 `-text` 变体（亮色下对比度）。

## 4 · 深度语法（两级 + 两档）

| 层 | 形态 | 规格 | 谁有 |
|---|---|---|---|
| 硬阴影 | `0 Npx 0 var(--hard)`（零模糊） | 控件 3px / **其余一律 4px**（含弹窗） | 所有凸起元素 |
| 环境影 | `0 26px 70px var(--drop)` | 仅确认弹窗 | 离地悬浮的对象 |
| 彩色例外 | `0 4px 0 var(--*-deep)` | 同色相加深，不用中性 hard | 绿/黄/蓝/红按钮 |
| 发光 | `0 0 Npx` | LED 呼吸（2.4s 循环）、黄待确认脉冲 | 不算投影体系 |

- **按下态**：`translateY(3-4px)` + 阴影缩至 1px/none——位移量 = 被压缩的厚度
- **容器无投影**：窗体与托盘菜单不画阴影（方案 1——真实投影由 OS 提供，原型不伪造）
- **硬阴影永为家族最深中性色**（铁律 3）；彩色按钮例外走同色相加深

---

## 5 · 边框策略

- **容器之间零边框**（窗体、标题栏/侧栏分隔、底条、内容卡全部无边框）——分层完全由材料对比 + 留白承担
- **元素级边框保留三档**（`--line` 系）：糖果卡、按钮、输入框、徽标、弹窗/切换钮激活态
- 玻璃顶缘高光 `--rim`：`inset 0 1px 0` 加在玻璃块阴影列表首位（窗体、弹窗、托盘）

## 7 · 布局骨架（960×640 主窗）

| 区 | 规格 |
|---|---|
| 窗体 | 960×640，圆角=OS（Win11 DWM ≈8px，2026-09-21 裁决；原型 18 仅存演示） |
| 标题栏 | 高 44，透明（玻璃一体）；左：闸门徽记 + remote-tools + 副题；右：最小化/最大化按钮 |
| 侧栏 | 宽 64，透明；导航钮 44×44（圆角 13），底部 LED；激活态 = surface-2 底 + accent-text + 3px 硬阴影 |
| 内容区 | `.viewwrap` margin `10px 10px 0 0`（上右留白、左贴侧栏、底沉底条）；卡圆角 16，`overflow:hidden` |
| 底条 | 高 34，透明（纯玻璃节奏条，无内容） |
| 弹窗 | 448 宽，圆角 20，顶部色带头（红/黄）+ 乳白体 |
| 托盘菜单 | 236 宽，圆角 14，`--glass` 同窗体透明度，无指向三角 |

## 8 · 状态语义

| 状态 | 视觉 |
|---|---|
| 托盘·已连接 | 绿色闸门徽记 + 绿 glow |
| 托盘·未连接 | 灰徽记（`--ink-3`） |
| 托盘·待确认 | 黄徽记 + 1.6s 脉冲 glow |
| 侧栏/横幅 LED | 绿点 + 2.4s 呼吸（opacity 1↔.55） |
| 流水行判定 | 自动放行（绿徽）/ 人工确认后放行（黄徽）/ 已拒绝（红实底徽 + 行体 color-mix 红 7% 实底 + 红边） |

## 9 · 禁区（Anti-slop 契约）

- ❌ 容器之间画边框 / 容器画投影（窗、托盘）
- ❌ 半透明染料直接坐在玻璃上（铁律 1）
- ❌ 亮色用暖米灰/暖棕阴影（历史教训："脏"）
- ❌ 糖果色作装饰（不表状态就是错）；红色用于非危险场景
- ❌ emoji 图标、紫渐变、圆角卡片+左彩边、SVG 画 imagery
- ❌ 编造数据填充（流水必须真实操作）
- ❌ 用 Tauri 原生菜单 API 做托盘菜单（样式不可控，须自绘）

## 10 · 实现映射（Plan B Task 8）

1. **token 平移**：本表 3.1/3.2/3.3 逐字转成 `ui/styles.css` 的 `:root` 与 `[data-theme="light"]` 变量；`.app/.viewstage/.modal/.traymenu` 等结构的 CSS 直接参照 roulette.html 对应类。
2. **主题切换**：`document.documentElement.dataset.theme`，localStorage 键 `rt-theme`，暗色默认（删除 attr 即暗色）。
3. **Tauri**：v1 用 CSS backdrop-filter 玻璃（跨平台逐像素一致）；可选增强 `windowEffects`（Win: mica/acrylic；macOS: vibrancy）+ 页面底透明。外层窗体投影/圆角交给 OS。
4. **演示件不进产品**：`.stage/.aurora/.deco-*/.console/.demo-btn`（控制台与布景）、`--bg-stage/--vignette/--dotgrid/--bg-win/--bg-bar/--bg-rail/--glass-2/--line-win/--tray-bg`（已废弃或布景专用 token）。
5. **图标**：闸门徽记（圆角方 + 门拱 + 门槛线）的 SVG 内联模板在 roulette.html，`fill="currentColor"` 由父级语义色控制；门拱镂空填背景 token。
